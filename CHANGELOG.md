## [1.0.0] - 2026-09-18

Первый стабильный релиз.

### Added

- Локальный веб-интерфейс для моделей Ollama: чаты, сообщения,
  вложения.
- Стриминг ответов модели через polling (700 мс).
- Загрузка `.md` / `.txt` в чат как вложение. Содержимое уходит
  модели один раз system-сообщением в начале промпта.
- Экспорт любого сообщения в `.md`-файл.
- Автоматическое имя чата по первому сообщению.
- Кнопка мягкой остановки генерации.
- Возобновление polling после перезагрузки страницы.
- Markdown в режиме чтения, редактирование в textarea.

### Security

- XSS-защита: Markdown рендерится с `escape=True`, сырой HTML из
  ответов модели и загруженных файлов экранируется.
- CSRF-защита на всех POST-запросах через токен в сессии.
  HTMX подставляет заголовок `X-CSRFToken` автоматически.
- Защита от DNS rebinding: Host allow-list (`127.0.0.1`,
  `localhost`, `[::1]`), fail-closed на пустой Host.
- `SECRET_KEY` создаётся через `os.open(O_CREAT|O_EXCL, 0o600)` —
  без окна world-readable. Запись завершается `fsync`.
- Ограничения на размер файлов и общий объём вложений.
- Атомарная резервация слота стрима — второй запрос в тот же чат
  получает 409.

### Fixed

- При отказе `try_reserve` (гонка между пре-чеком и резервацией)
  откатываются оба сообщения — user и placeholder-assistant. Раньше
  user-сообщение оставалось без ответа.
- `stop_generation` не обнуляет уже видимый контент.
- Polling не теряется при перезагрузке страницы во время стрима.
- Ошибки 4xx от HTMX-эндпоинтов доставляются в UI через
  `HX-Retarget` и `beforeSwap`-override.

### Известные ограничения

- Отмена генерации — мягкая. Ollama прекращает работу в течение
  1–2 секунд после закрытия соединения клиентом. Гарантированная
  остановка — перезапуск `ollama serve`.
- Один воркер WSGI. `StreamManager` хранит стримы в памяти процесса.
- Аутентификации нет. Приложение слушает только `127.0.0.1`.
